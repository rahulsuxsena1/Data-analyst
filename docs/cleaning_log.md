## Decisions that need a human to agree with them

- **Dates in `DD/MM/YYYY`** are read day-first because the source system exports that way. With a new data source, check this before anything else: a wrong guess silently swaps months.
- **Rows with a missing rating or date are dropped, not imputed.** Imputing the target variable would invent the very thing we are trying to measure.
- **Impossible model years are nulled, not dropped.** The review is still valid for every question except Q5 (model-year comparison), which filters nulls out.
- **Brand typos are fixed with fuzzy matching (cutoff 0.8)** against a fixed list of known brands, so a new brand would be dropped, not guessed. Check the 'unmappable' count on new data.
- **The original text is kept** in `review_text` for display; `text_lower` is only used for tagging.

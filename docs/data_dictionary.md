# Data dictionary

> **Synthetic data (Route B).** Every brand, model, reviewer and review in this project is fictional,
> generated by `src/generate_data.py` (seed 42). The structure mirrors public car-review datasets
> (Edmunds-style), so a real dataset can replace it by swapping one file. See "Switching to real data" below.

## Source

| Item | Value |
|---|---|
| Source | Synthetic, `src/generate_data.py` |
| Licence | Generated for this project; free to reuse |
| Period covered | Jan 2020 to Dec 2025 (review dates) |
| Raw rows | 12,360 (`data/raw/reviews.csv`) |
| Clean rows | 11,496 (`data/clean/reviews_clean.csv`); see `docs/cleaning_log.md` |
| Brands / models | 8 fictional brands, 18 models, model years 2015 to 2025 |

## Raw columns (`data/raw/reviews.csv`)

| Column | Type | Description | Known problems in the raw file |
|---|---|---|---|
| `review_id` | text | Unique review ID | Exact duplicate rows share an ID; re-posts have a new ID |
| `reviewer` | text | Anonymous reviewer handle | |
| `brand` | text | Car brand | Case, spacing and spelling variants (`VELORA`, `Velorra`, `Tamaru Motors`) |
| `model` | text | Car model | Lower-case variants, trailing spaces |
| `model_year` | number | Model year of the car | Impossible values (2202, 1900, 0, blank); stored as float |
| `review_date` | text | Date of the review | Three formats: `2023-04-12`, `12/04/2023` (day first), `Apr 12, 2023`; blanks; dates in 2031 |
| `rating` | text | Star rating, 1 to 5 | Blanks, out of scale (0, 6, 10, -1), text such as `4 stars` |
| `review_title` | text | Short title | |
| `review_text` | text | Full review | HTML tags (`<br>`), entities (`&amp;`), blank or `N/A`, padding spaces |
| `dealer_region` | text | Region of the selling dealer | |
| `verified_purchase` | bool | Purchase verified by the platform | |

## Added during cleaning and analysis

| Column | Where | Description |
|---|---|---|
| `text_lower` | clean | Lower-cased text, used only for keyword tagging |
| `review_year`, `review_month` | clean | From `review_date` |
| `rating_band` | clean | `1-2 (negative)`, `3 (neutral)`, `4-5 (positive)` |
| `sentiment_label` | clean | **Weak label** from the rating: 1-2 negative, 3 neutral, 4-5 positive |
| `word_count`, `car_age_at_review` | clean | Length of review; review year minus model year |
| `has_<theme>` | themes | 1 if any sentence mentions the theme (keyword dictionary) |
| `neg_<theme>`, `pos_<theme>` | themes | 1 if the theme's sentence(s) score negative / positive with VADER |
| `n_themes` | themes | Number of themes mentioned |
| `vader_compound` | themes | Whole-review VADER score, -1 to +1 |
| `mixed_flag` | themes | Review has at least one positive and one negative theme |
| `text_rating_conflict` | themes | Text scores clearly positive (VADER >= 0.5) but rating is 1-2: possible sarcasm or misclick |
| `predicted_sentiment` | sentiment | TF-IDF + logistic regression prediction |
| `in_test_set` | sentiment | 1 if the review was in the held-out 20% test split |

Themes: `service`, `price`, `maintenance`, `reliability`, `comfort`, `mileage`. Keywords are in `src/themes.py`.

## Limitations

1. **Synthetic.** Findings describe the generator, not a market. They show that the *method* works
   (see `docs/pipeline_validation.md`) and must not be quoted as real facts.
2. **Star ratings are weak sentiment labels.** A 4-star review can contain a serious complaint.
3. **Self-selection.** Real review sites over-represent very happy and very unhappy customers.
4. **Keyword tagging misses indirect phrasing** ("towed twice in six months" has no reliability keyword).
   Measured recall is about 77%, precision about 99%.
5. **Small groups.** Brixton has 98 reviews; some model-year cohorts have under 50. Queries apply minimum counts.
6. **Templated text.** Synthetic reviews reuse sentence templates, which makes text models look better
   than they would on real data.

## Switching to real data

1. Save the dataset as `data/raw/reviews.csv` with the raw columns above (rename columns if needed).
2. Update `CANONICAL_BRANDS` and `DATE_FORMATS` in `src/clean.py`.
3. Run `python run_pipeline.py --real` (skips the generator and planted-signal validation).
4. Hand-label ~200 reviews for themes and sentiment to replace `docs/pipeline_validation.md`.
